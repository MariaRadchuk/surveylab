# Frontend SurveyLab

Статична сторінка викладача (створення опитування з шаблону «Оцінювання якості
курсу» і список опитувань), яку віддає Nginx. Запити `/api/` і `/health`
Nginx проксіює до сервісу `backend` у мережі Docker Compose.

Заплановані екрани: конструктор опитування, сторінка проходження, аналітика результатів.
